# Dragon Wave — make.fun "Make the AI judge excited" (ai-excited-01)

## Concept

A colossal ocean wave curls overhead and becomes a roaring dragon, its
watery head and open jaws formed by the crest itself, seconds away from
crashing down on one tiny lone surfer far below. Golden sunlight pierces
through the translucent teal barrel, lighting the wave from within.

Why it stands out: the twist is scale and transformation — the wave *is*
the creature, not a backdrop for one. One huge dominant shape (the
wave-dragon) fills the frame, so the image still reads at thumbnail size,
while the tiny surfer gives it vertigo-inducing scale and a frozen moment
of momentum: impact is about to happen, but hasn't yet. No text inside the
image, so nothing can render broken.

The artwork is an original AI-generated image (`entry.png`, 600×900 PNG).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This copies `./entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output/entry.png`). Node 22+, standard library only — no
dependencies to install.
