# Dragon Wave — the wave is the dragon

A giant ocean wave curving into a roaring dragon: the wave's peak is the
dragon's head with open jaws, a tiny lone surfer far below, golden sunlight
shining through the translucent barrel. Deep teal, gold, and white foam.

## What it is

An image entry for the make.fun **ai-excited-01** bounty: `entry.png` is the
artwork, and `main.ts` copies it byte-for-byte to the output directory,
verifying integrity with a SHA-256 hash.

## Run

```sh
node --experimental-strip-types main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the destination directory (default `/output`).
