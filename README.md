# Dragon Wave — the wave is the dragon

A giant ocean wave curving into a roaring dragon: the wave's peak is the
dragon's head with open jaws — the wave IS the creature. One tiny lone surfer
rides far below, dwarfed by the golden-lit barrel. Deep teal, gold, and white
foam; no text.

## What it is

An original AI-generated image (`entry.png`) for the make.fun
[ai-excited-01](https://make.fun/bounty/ai-excited-01) bounty. `main.ts`
copies `entry.png` to the output directory and verifies the copy is
byte-identical to the source via a SHA-256 hash.

## Run

```sh
node --experimental-strip-types main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose the output directory (default `/output`).
